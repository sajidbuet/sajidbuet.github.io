## 1. Architecture: what is whose

This matters more than any colour value, because it determines where changes are allowed to go.

| Layer | Location | Editable? | Contents |
|---|---|---|---|
| **1. Upstream HugoBlox** | Hugo module cache | ❌ never | `HugoBlox/kit/modules/blox@v0.11.0`, `slides@v1.2.5`, `integrations/netlify@v1.2.1`, `analytics@v0.3.1` |
| **2. Vendored copy** | `_vendor/github.com/HugoBlox/kit/modules/` | ❌ never edit | `hugo mod graph` shows **all four modules resolving `+vendor`** — the build reads this tree, not the module cache |
| **3. Project overrides** | `layouts/`, `assets/css/`, `config/` | ✅ **this is the target** | Files that shadow upstream paths |
| **4. Custom SAJID.BD** | `layouts/_partials/custom/`, `layouts/_partials/hbx/blocks/<custom>/` | ✅ fully owned | Blocks and partials with no upstream equivalent |

**Rule for Phase 2+:** all changes land in layer 3 or 4. Never `_vendor/`, never the module cache,
never `public/`.

Because modules are **vendored**, an upstream upgrade is `hugo mod vendor` — and it will silently
overwrite `_vendor/`. Anything customised must live outside it.

## 6. Motion inventory

Measured on `/` at 1440 × 900: **14 running animations, all infinite**; 231 elements with a non-zero
`transition-duration`; **19 elements with `backdrop-filter`**; 4 with `filter: blur()`.

| Animation | Duration | Iterations | Source | Reduced-motion | Classification |
|---|---|---|---|---|---|
| Hero mesh `pulse` ×3 | 2000 ms | ∞ | `gradient_mesh.animation` | ❌ **ignored** | Decorative — **excessive** |
| Logo typewriter (`Lab` ⇄ `.BD`) | ~0.9 s/char | ∞ | `logo-loader-loop.html` | ✅ honoured | **Distracting** (concept good, loop bad) |
| `pulseS` | 1800 ms | ∞ | logo SVG | ✅ | Decorative — neutral |
| `wifiPulse` ×3 | 1600 ms | ∞ | logo SVG | ✅ | Decorative — neutral |
| `jNodePulse` ×n | 1400 ms | ∞ | logo SVG | ✅ | Decorative — neutral |
| Scroll-reveal (opacity 0→1) | — | once | stats/cards | not checked | **Accessibility-sensitive** (P1-05) |
| Nav brand hover | 300 ms | — | `hover:-translate-y-0.5 hover:scale-[1.02]` | n/a | Useful |
| Button hover | 300 ms | — | `hover:-translate-y-0.5 hover:shadow-lg` | n/a | Useful |
| Card hover | 300 ms | — | `group-hover:` transforms | n/a | Useful |
| Header backdrop blur | static | — | `custom.css` | n/a | **Performance-affecting** |
