## Motivation

Seating students in roll-number order during a class test discourages groups of
students who might otherwise sit together and collaborate. Producing that
seating chart by hand in PowerPoint or Excel before every test is slow and has
to be repeated for each room and each cohort.

## What it does

CTAdmin generates the seat plan from a roll-number list and provides the timing
function needed while the test is running, so both parts of running a class test
are handled by one tool rather than a spreadsheet plus the operating system's
timer app.
